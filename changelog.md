# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog.

## [0.5.19] -2026-07-19

### Changed
* Preserved URL now works for chinese characters and Penyim

## [0.5.18] -2026-07-11

### Added

* Searches are now done on a new page /search/[term] and not in /.

* Added  button so the user can jump to the top of the page rather than manually scrolling


### Changed

* Updated icon image paths.


## [0.4.18] -2026-06-16

### Added

* Allow search by Cantonese and Taishanese, in addition to English and Mandarin.
* Translation API response updated to include Cantonese and Taishanese.

### Changed
* Separate enum `LanguageFormat` into `SearchLanguage` and`PenyimFormats`.

## [0.3.18] -2026-06-10

### Added

* Added project changelog.
* Added version tracking and release documentation process.

### Changed

* Standardized project release management.
